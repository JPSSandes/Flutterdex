# O QUE É A FLUTTERDEX?

A Flutterdex é um mock-up de uma pokédex feito utilizando os
recursos da linguagem Dart juntamente do framework Flutter para
desenvolvimento mobile híbrido.

## ESCOPO DO PROJETO

Este projeto faz parte de um trabalho dedicado à disciplina optativa
de Programação Móvel dentro do curso de Bacharelado em Sistemas de
Informação no IFBA (Instituto de Ciências e Tecnologia da Bahia), e
de acordo esta natureza, não planejo transformar este app em um programa
próprio, mas sim uma ferramenta de aprendizado. 

## OBSERVAÇÕES

O projeto tem apenas o front-end, o back-end será adicionado posteriormente
utilizando a linguagem C#. Se você está vendo o projeto e deseja ampliar nele,
fique a vontade para fazer fork do projeto e expandir o programa.
