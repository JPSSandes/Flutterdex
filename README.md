# O QUE É A FLUTTERDEX?

A Flutterdex é um mock-up de uma pokédex feito utilizando os recursos
da linguagem Dart juntamente do framework Flutter para desenvolvimento
mobile híbrido.

## ESCOPO DO PROJETO

Este projeto faz parte de um trabalho dedicado à disciplina optativa de
Programação Móvel dentro do curso de Bacharelado em Sistemas de Informação
no IFBA (Instituto de Ciências e Tecnologia da Bahia) e, de acordo esta
natureza, não planejo transformar este app em um programa próprio, mas
sim uma ferramenta de aprendizado. 

## OBSERVAÇÕES

1. O projeto tem apenas o front-end, o back-end será adicionado posteriormente
utilizando a linguagem C#. Se você está vendo o projeto e deseja ampliar nele,
fique a vontade para fazer fork do projeto e expandir o programa

2. Para rodar o programa, o mais recomendado é que seja utilizado o emulador
de android disponível no Android Studio

3. Caso você esteja utilizando o mesmo sistema operacional que eu (Fedora 44
KDE Plasma Desktop), imagino que possa rodar o programa sem muitas complicações.
Mas caso esteja utilizando outro sistema operacional e/ou der algum problema na
execução, é recomendado apagar a pasta Android do projeto e depois rodar o seguinte
comando:

`flutter create --platform=android .`

4. Por questões de simplicidade, só adicionei 23 espécies Pokémon no programa
seguindo em partes a ordenação oficial da franquia
